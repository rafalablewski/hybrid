HYBRID. Layout studies

Five ways to organise Today & Cockpit — same content, same skin, different information architecture.
The visual style is held constant on purpose: the only variable here is where things go and how they're grouped.
Layout 1

Priority Stack

One focus-first column, ranked top-to-bottom by importance. Duplicated bits (on-track / check-in / fuel) merge into a single status row; minor modules collapse to compact rows.

Layout 2

Bento Grid

A glanceable mosaic — tile size encodes importance, almost nothing below the fold. Read the whole day / whole system at once; tap a tile to drill in.

TodayCockpit
Layout 3

Segmented Tabs

A sticky segmented control splits each screen into categories (Train/Recover/Plan/Connect · Snapshot/Performance/Training) so it never out-scrolls one theme. JS-off safe.

TodayCockpit
Layout 4

Vitals Rail

The numbers you check first are pinned in a strip that stays put while detail scrolls beneath. At-a-glance vitals separated from depth.

TodayCockpit
Layout 5

Agenda / Timeline

Organised by when: Today on a day-clock spine (check-in → session → fuel → evening); Cockpit hung off a season periodization axis (phase done → now → event).
