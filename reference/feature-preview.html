Configurable workout loggershipped · #6

A Logger settings screen makes the live workout’s behavior yours. Defaults match today’s behavior — nothing changes until you opt in. core/logger-prefs.ts

Count warm-ups in volume
Include warm-up & cool-down sets in Volume / Trends. Off = excluded (RP-style). PRs always exclude warm-ups.
Detailed mode
Show the RPE column. Off = just load × reps.
Get-ready count-in
5→1→GO before the clock starts.
Auto rest timer
Start a rest countdown after each banked set.
Carry over last set
Pre-fill a new set with the previous load & reps.
Keep screen awake
Stop the screen dimming mid-set.
Haptics
Vibration on banking a set / rest done.
Default rest
60s 90s 120s 180s
