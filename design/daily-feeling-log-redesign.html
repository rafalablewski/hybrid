Recovery — Feel

Daily feeling log — five ways to log more than once

Today you log how you feel once and it sticks. These five redesigns make the feeling log a living daily signal: you must log at least once a day, and you can re-log anytime — capped at once every 6 hours. Each concept solves the same two states: unlocked (log now) and cooling down (a live countdown to the next check-in). Built in the Aurora system — the same faces, tokens and type the app already ships.

How you felt today, top to bottom

Each log becomes a node on a vertical spine so a day of feelings reads as a story. The live logger sits at the bottom — tap a face to add the next reading. Answers "how has today gone?", not just "how are you now?".

3Day Windows

Morning, midday, evening slots

The 6h cadence maps naturally onto parts of the day. Filled windows show the face + time; the current window glows lime and is the only one you can act on. The daily requirement is obvious — an empty slot reads as "not done yet".

How each handles the two states. Unlocked → tap a face / press the primary and it writes a new check-in row (energy=sleep=soreness=mood set to the picked 1–5, same as today's quick picker). Cooling down → the same surface swaps to a live countdown ("3h 51m to next") and the log target is disabled until 6h since the last write. The daily requirement is a "≥1 today" nudge on Home; re-logs beyond the first are pure upside.
