PropertyValueWhy that
faceF.mono, fs.micro (11)A label, not a control — the house grammar for a label is mono uppercase.
trackingtracking.caps (1.2)The token, not the literal that used to be typed into both rails.
colourC.ashAn exit never goes anywhere the accent should announce. Chartreuse is act now.
chromenoneNo fill, border, radius or shadow — a bordered box at the end of a thing reads as one more item of it. No ring either: rings belong to rail tails and door rows.
targethitSlop 14 / 16Clears the 44dp floor without padding, which would break the baseline it shares with the pill.
positionmarginLeft: autoPinned to the far edge of the actions row, so one action still sits leading and the exit still lands trailing — and when pills wrap, it rides the last line.
arrownested mono runArchivo has no →; CtaLabel sets the arrow in JetBrains Mono so it can't fall back to a mismatched system glyph.
 
// logbook-rail.tsx — the logged day
<AActionPair
  align="leading"
  actions={[
    ...(day.isToday ? [{ label: t("w.home.today.alsoTodayLogFirst"), onPress: onLog }] : []),
    ...(onLogSport ? [{ label: sportLabel, onPress: () => onLogSport(day) }] : []),
  ]}
  trailing={<HistoryExit onPress={onHistory} />}
/>

// week-rail.tsx — the finished plan day: nothing to do, still leavable
<AActionPair align="leading" actions={[]} trailing={<HistoryExit onPress={onHistory} />} />

One component, one arrangement, two rails. If the exit should move to the header slot or become a door row instead, it is this one prop in these two places — the rest of the change (the tick, the column, the edge) is independent of where it lands.
