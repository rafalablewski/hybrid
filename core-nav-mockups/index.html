Top Nav Redesign

Fifteen standalone directions for the CORE top navigation, each a different architecture — not a reskin. Every file renders all five surfaces (POS · KDS · Orders · Service · Guest) so you can compare like-for-like. Set 1 explores nav structure; Set 2 borrows a signature aesthetic from a brand or design tradition.

Set 1 · structural

01

Cockpit

One 60px row, three fixed zones. Identity + context · centered segmented section switch · divider-grouped utilities. The safe professional standard.

→ 02

Two-Tier

Thin global utility strip on top, bold contextual working row below. Cleanly separates “the venue” from “this screen.”

→ 03

Islands

Floating Liquid-Glass capsules that morph per surface. Dynamic-Island / visionOS energy, reusing CORE’s existing glass material.

→ 04

Switchboard

Makes the module switch the hero — labelled switcher + quick-jump icon rail — and collapses the four loose status pills into one cluster.

→ 05

Editorial

Big 900-weight section wordmark, mono underline tabs, metrics instead of pills. Accent reserved for state only. Legible across the room.

Set 2 · inspired by

06

Apple

macOS / visionOS vibrancy: translucent backdrop-blur bar, circular mark, sliding-pill segmented control, system-blue accent. Quiet and precise.

→ 07

Lucid

Lucid Motors luxury: expansive whitespace, hairline-thin wide-tracked type, a cosmos gradient, aurora underline. The premium-EV-cockpit end.

→ 08

Tesla

Model-S touchscreen: near-monochrome, big soft-cornered touch targets, white primary, colour used only for alerts. Glance-and-gloved-finger.

→ 09

Nvidia

GPU-console: carbon-black on a technical grid, signal-green accent, angular cut-corner panels, monospaced uppercase data labels.

→ 10

Japandi

Your repo's warm light theme: oat-paper surfaces, clay accent, a Fraunces serif for the section name. Feels like paper, not a screen.

→ 11

Swiss

International Typographic Style: a strict modular grid of ruled cells, black / white / signal-red, sharp corners, labelled data compartments.

→ 12

Minimal

Everything removed but meaning: a single hairline baseline, text-only tabs, whisper-weight icons, status as plain figures. Content-first.

→ 13

Professional

Enterprise ops console (Bloomberg / Linear): a seamless bar of ruled compartments — identity, section, tabs, and every KPI labelled. Dense, not messy.

→ 14

Command (mine)

Keyboard-first terminal bar: traffic-light chrome, a live shell prompt (core ❯ pos:order), mono tab chips, ⌘K launcher, terse telemetry.

→ 15

Aurora (mine)

The flagship: CORE wearing HYBRID's real acid-lime Aurora identity — ambient edge-glow, glowing segmented tabs. The hero-screenshot option.
