Builder — five redesign concepts

The routine Builder, re-thought in the Jony-Ive vocabulary. Every concept fixes the same four sins of the current screen: the save-slots note is never occluded (the layout reserves clearance for the floating nav by construction), exactly one chartreuse action per screen ("+ Add set" stops impersonating the primary), ghost placeholders that cannot be mistaken for data (dim, italic, or simply absent), and each number is said once — the card no longer narrates the table that narrates the tiles.

Concept 01 — The Ledger

One slab. The routine is a list, not a stack of machines.

The current screen wraps every exercise in its own heavy card with its own summary strip — boxes in boxes. Here the whole routine is one machined slab divided by hairlines: collapsed exercises read as a scannable ledger line (name + one hairline meta), the open one expands in place with a plain mono set table. Totals live in ONE meta line under the title — nowhere else. Drag handle for reorder; no ↑↓ buttons.

Concept 02 — One Number

The routine has a weight. Feel it grow.

Ive's instinct: find the one honest number and let it be the interface. The three stat tiles and the balance card collapse into a single live readout — the session's estimated time — with tonnage and balance as its quiet meta. Every exercise you add visibly moves the number, so composing feels like loading a bar, not filling a form. The list below is deliberately plain; the number is the product.

Concept 03 — One at a Time

Edit one exercise. The rest wait their turn.

The current screen shows every set grid of every exercise at once — a wall of inputs. Here the Builder becomes a focused flow: one exercise fills the screen (its name in the serif display voice, its sets as the only inputs), the others wait as a quiet queue below. One chartreuse action that reads "Next" until the last exercise, where it becomes "Save". Placeholders are italic ghosts — unmistakably not data.

Concept 04 — The Bar

A clean list, a sheet to edit, a bar that owns Save.

Separate scanning from editing. The screen itself is just tidy exercise rows in the Today deferred-row anatomy — tap one and a bottom sheet opens with its set grid (the editing chrome never lives on the list). A persistent action bar carries the live totals and the ONE chartreuse Save, docked above the tab bar — the occlusion bug becomes structurally impossible, because the bar is part of the layout, not content scrolled under the nav.

Concept 05 — Just the Numbers

No boxes. The numbers are the interface.

The most radical cut: remove the input chrome entirely. Exercise names in the serif editorial voice; each set is a line of pure mono type on a hairline — tap any number and it underlines in chartreuse and becomes editable in place (the underline is the only accent on screen besides Save). Nothing looks like a form, so nothing looks pre-filled: a set you haven't touched simply isn't there yet. "+ set" is quiet type, not a pill.
