HYBRID — Light theme redesign — Concept 07

Milk & Ink

The most restrained answer: colour nearly retires. Milk surfaces, near-black ink, and a single terracotta thread kept for tiny accent text. The Start button is ink — the darkest, most confident object on the screen — so the action needs no colour to be found. Instrument Serif at display size gives the screen the intimacy of a printed magazine page rather than a dashboard.
