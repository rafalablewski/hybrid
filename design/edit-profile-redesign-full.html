Edit profile — six full-screen redesigns

Not just the avatar block — the whole screen. Six directions rethink the header, the photo/preset picker, every field, the inputs, the cards, the Done button and the way you actually edit. Same data, same brand (chartreuse, Sohne, SohneMono). Swatches are live — tap them.

1 Refined

Refined

The lowest-risk ship. Keeps today's three blocks but fixes the rhythm: one radius system, a glow-lit avatar, the active preset gets a name, the upload becomes a clear ghost pill, and the field rows get real hierarchy (label / value / chevron) instead of floating text.
