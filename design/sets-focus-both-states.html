HYBRID · Active workout · two logging habits

One design, both kinds of lifter. The active set is always the first unlogged one.

The screenshot only shows the plan-ahead case (5 empty rows queued). But many lifters add one set at a time — do it, log it, add the next — so there's no queue at all, and their most-tapped control is + Add set. Below, each concept is shown in both states so we can confirm one treatment holds for both before building.

The rule that unifies them: there is always exactly one active set — the first unlogged one. History above it recedes; any plan below it recedes further; and when nothing is below it, + Add set inherits the "what's next" role and steps forward as a primary action.

What the pairing shows. Every concept survives both habits with the same component — the difference is only whether a plan sits below the live set, and whether + Add set is elevated (incremental) or quiet (plan-ahead).

Hold cleanest for both: 01 Quiet ledger and 03 Descending tone — one component, future section optional, add-set swaps weight. Diverge most: 02 The one set — the incremental lifter loses the "how many left" story, so it's only right if planning-ahead is the majority.

My recommendation: build 01 Quiet ledger with the elevated add-set behaviour — it serves the one-at-a-time lifter's core loop (log → add → log) while still fading the queue for planners, and keeps every set visible for those who want it.
