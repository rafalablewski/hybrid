Five layouts that survive many sets

You're right: the moment a lift has 4+ blocks (Power Clean & Jerk: 60%×3+1×2 · 70%×3+1×2 · 80%×2+1×2 · 90%×2+1×2), the prescription fights the name for width. These five each handle any number of sets without squeezing the name or overflowing the row — shown on the worst-case Day 1.

The test case → every concept below is rendered with the 4-block Power Clean & Jerk and 3-block lifts side by side. If the name stays readable and the sets stay tidy on both, the layout passes.

06

Percent Matrix

Load becomes the column axis: fixed 60 / 70 / 80 / 90 headers, lifts are rows, reps fall into the matching cell. A lift with 4 working percentages just fills 4 cells — the row never grows wider, names never shrink. Vertically aligned, so you can read "what's the 90% work today" straight down a column.

Fixed column count — sets can't push the name. Infinite reps per cell.

07

Name-Top Stack

The simplest fix: the name gets its own full-width line, and the set chips wrap underneath across the entire card width. Name and data never compete for the same horizontal space, so 8 sets just wrap to a second line. Reads top-to-bottom like a coach's notes.

Name owns its own line — zero width competition. Chips wrap freely.

08

Swipe Rail

The name is pinned in a fixed left column; the sets live in a horizontal-scroll rail with an edge fade hinting "more →". Any number of sets fits in the same row height — you swipe/scroll the rail instead of reflowing. Excellent on mobile, where this is the natural gesture. (Try scrolling the Power Clean rail sideways.)

Name column fixed; sets scroll horizontally — row height is constant.

09

Load Sparkline

Each set becomes a bar whose height is its intensity — the whole working scheme reads as a tiny shape (ramp, wave, plateau). 8 bars occupy the same footprint as 3; the name keeps a fixed column. You feel the day's load progression instantly, with exact numbers on each bar. Most distinctive of the five.

N sets → N thin bars in a fixed-height chart. Footprint barely grows.
