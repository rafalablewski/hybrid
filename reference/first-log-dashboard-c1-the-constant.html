The Constant — one calendar for the whole life of the account

The dilemma: a plan-less logger sees the three onboarding cards forever — five workouts by Friday and still no calendar. The move: the week rail that plan users already get is not a plan feature — it is the account's spine. After the very first logged session it mounts in logbook mode: same chips, same receipts, same geometry — only the content differs (logged days instead of prescribed days). The three cards demote to three slim rows under a quiet "Add structure" head. When a plan is enrolled, nothing is replaced — the same rail simply starts showing prescriptions. One object, filling up with the user's life.

The design argument

We don't add a calendar as a reward. We admit it was always there — training just makes it visible. A logbook day has no "missed" state: greyscale means "no promise was made", so an un-logged Wednesday is silence, never terracotta guilt. The interface never changes shape on the user; it only changes fill.
