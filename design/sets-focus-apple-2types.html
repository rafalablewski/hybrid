Ten material concepts, each built for both habits. The material shows who you are.

Same Apple direction — glass, depth, live activities, tactile controls — but now every concept answers the split you flagged. Left = adds one at a time (no queue; the material turns + Add set into the next object, progress is open-ended). Right = plans ahead (a real queue fades below; progress has a denominator). Same exercise: Front Raise, Set 4, 5 kg.

One rule underneath all ten: the active set is always the first unlogged one. When a plan sits below it, the queue recedes and progress reads 4 of 8. When nothing sits below, + Add set becomes the next material object — a ghost card, a deck to deal, an open arc — and progress goes indeterminate.

The throughline. Every concept resolves the two habits with a single component: the material simply changes state. Add-set becomes an object (ghost card, dealt card, + cap, open arc) for the one-at-a-time lifter; a real queue + denominator for the planner.

Cleanest metaphor: 01 Glass + ghost add — the ghost that solidifies into the next set is the truest read of "adding as you go." Fastest to ship: 09 Vibrancy row — one tinted row + a mode-swapped accessory. Most Apple: 10 Island morph and 04 Open-vs-full ring.

My recommendation: build 01 Glass + ghost add as the hero, borrowing 02's pinned capsule for long lists and 09's tinted-row restraint as the low-risk fallback. All are pure presentation over the "first-unlogged-set" state — no data-model change. Tell me which to build (web + mobile) and whether the incremental add should auto-carry the last set's weight.
