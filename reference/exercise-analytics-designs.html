HYBRID – ANALYZE – EXERCISES

Exercise analytics — 10 design concepts

Per-movement deep analytics for the Exercises tab, in the HYBRID dark system — ink surfaces, hairline borders, 28-px cards, JetBrains Mono numbers, Aurora accents. Every concept is computed purely from logged sessions (exerciseDashboard-style aggregators in @hybrid/core), so it works for both clients and offline. Worked examples: Deadlift (strength) and Running (cardio).

FREE FOR ALL — the Exercises tab is ungated: casual/free users get every concept below. No paywall inside this screen.

Intensity distribution — where your sets live

SHARE OF WORKING SETS BY % OF E1RM — THIS YEAR
Why: a histogram of every set by relative intensity, with the training quality named under each band (speed / volume / strength / peak). One glance answers "am I grinding maxes too often?" or "have I touched 90 %+ at all this block?" — the classic coach's-eye check, automated.

IMPLEMENTATION NOTES
All ten concepts derive from data we already log (sets × reps × load × RPE, runs with distance + time) — no new capture needed. Aggregators live in @hybrid/core beside exerciseDashboard; web renders recharts/SVG, mobile renders the same view-model with RN SVG. Rankings (7) needs the social schema for the club board; standards + percentile tables ship as static core data. Everything else is pure client math — free-tier friendly, offline-capable.
