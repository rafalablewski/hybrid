Command — responsive

A keyboard-first command bar: traffic-light chrome, a live shell prompt that states exactly where you are (core ❯ pos:order), monospaced tab chips, a blinking caret and a ⌘K launcher. Tuned for real devices — each bar is a CSS container, so the layout is driven by the bar's own width, not guessed from the viewport. Three tiers: full terminal row → condensed single row (iPad Pro portrait & iPad landscape drop loc + lights and collapse search to a ⌘K chip) → stacked (iPad mini + phones: prompt + telemetry, swipe-scroll tabs, wrapping actions).
